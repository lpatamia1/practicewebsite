# Java Flashcards & Quiz App

A simple **Java study tool** built with HTML, CSS, and JavaScript.
It includes two modes:
- **Flashcards Mode**: Review key Java terms and definitions.
- **Quiz Mode**: Test your knowledge with multiple-choice questions (including code snippets).

---

# Features
- 🃏 **Flashcards**
  - Navigate through a large set of Java flashcards
  - Click a card to reveal its definition
  - Mark cards as mastered (planned)

- 📝 **Quiz**
  - Multiple-choice questions (concept + code-based)
  - Immediate feedback on answers
  - Pulls from the same knowledge base as flashcards

- 🔄 **Mode Switching**
  - Switch seamlessly between Flashcards and Quiz modes
